> [!TIP]
> **0.4.13：ネイティブのグループ化された画面とディスプレイ制御。** システム情報、ディスプレイ、バッテリー、パフォーマンス、メモリの各画面に標準のグループ化フォームを採用。解像度・HiDPI・リフレッシュレートの切り替えに加え、対応機器では明るさ・コントラスト・音量・ICC プロファイルを調整できます。

MacScope は、Mac の重要な状態を見やすいネイティブ UI にまとめます。SwiftUI と AppKit で構築され、Electron、組み込みブラウザ、追加のランタイムは含みません。利用にターミナル、Python、Homebrew は不要です。

## MacScope を選ぶ理由

| | 特長 |
| --- | --- |
| **ネイティブ UI** | macOS 標準のウインドウ、メニュー、テーブル、設定、認証ダイアログ、ライト・ダーク表示 |
| **軽量** | 小さなアプリで、追加のランタイムや重い Web コンテナは不要 |
| **情報を集約** | CPU、電力、温度、ファン、メモリ、ディスク、ネットワーク、プロセス、保守ツールをひとつに |
| **操作が明確** | スキャン結果、パス、進行状況、失敗理由を表示し、削除対象はユーザーが選択 |
| **ローカル処理** | 監視とファイル分析は Mac 上で実行され、システム情報やスキャン結果をアップロードしません |

## 主な機能

### ネイティブのメニューバー監視

メインウインドウを開いたままにしなくても、Mac の状態を確認できます。

- モノクロアイコンのみ、または最大 3 つのコンパクトなリアルタイム指標を表示。
- CPU、GPU（Apple Silicon）、メモリ、ディスク、ネットワーク、温度、システム消費電力、充電電力を選び、順序を変更可能。GPU と電力の指標は初期状態では無効です。
- アップロードとダウンロードの速度を 2 行に表示。指標の幅が固定されているため、数値が変わっても他のメニューバーアイコンが動きません。
- アイコンをクリックすると、直近 1 分間の推移をダッシュボードに表示。
- CPU、メモリ、ディスク、ネットワーク使用量順で上位プロセスを確認。
- ダッシュボードのモジュールとプロセス数を変更可能。メインウインドウを閉じても監視は継続します。
- 初期設定はモノクロ表示。「Color Mode」を有効にすると、グラフと動的な状態表示に色が付きます。
- ポインタがパネルに入った後、外に出ると約 0.25 秒で自動的に閉じます。Settings > Menu Bar で無効にできます。
- メイン、設定、ヘルプの各ウインドウは、連続した半透明のサイドバーと不透明なコンテンツ背景で統一。macOS 26+ ではサイドバー、メニューバーパネル、結果ダイアログに標準の Liquid Glass を使用し、外観に応じて背景を調整します。Settings > Appearance > Liquid Glass で Glass・Balanced・Frosted を選択でき、即座に反映・保存されます。
- 標準タイトルバーとグレーのグループ領域で詳細画面を整理。情報画面には SwiftUI のグループ化フォームを使い、テーブル画面の余白とステータスバーも統一して罫線や枠を減らしています。
- 古い macOS では標準のぼかし素材を使用。どの素材も「透明度を下げる」「コントラストを上げる」に従います。
- Settings > Appearance で Dock アイコンを非表示にできます。メニューバーからウインドウと設定を開けますが、アプリ切り替え画面には表示されなくなります。Dock とメニューバーのどちらかは有効にしておく必要があります。
- Dock アイコンは標準でアプリの外観に追従し、Follow System 使用時はシステムのライト・ダーク切り替えにも追従します。Settings > Appearance > Dock Icon で Light または Dark を個別指定できます。Finder のアイコン表示は macOS のアイコンスタイル設定に従います。

### リアルタイムのリソース監視

発熱、ファンの回転上昇、ネットワークの遅延が起きたとき、状況を数値で確認できます。

- **CPU：** 合計、ユーザー、システムの使用率と SoC 温度。
- **GPU（Apple Silicon のみ）：** 合計使用率と直近 60 秒の推移。データがある場合はレンダラーとタイラーの使用率も表示し、管理者権限は不要です。
- **メモリ：** 使用量、合計、利用可能量、現在の使用率。
- **ディスク：** データボリュームの容量、読み込み・書き込み速度。
- **ネットワーク：** 現在のダウンロード・アップロード速度。
- **概要：** 左側のリングで現在値を表示し、右側のグラフで直近 60 秒のシステム負荷、ディスク、ネットワーク活動を比較。
- **状態に応じた色：** 使用率、通信速度、温度の範囲を色で把握。
- **更新間隔：** 一時停止、即時更新、`0.5`・`1`・`2`・`5` 秒間隔に対応。

### パフォーマンス・電力・冷却

高負荷、温度変化、ファンの動作を同じ画面で比較できます。

- CPU・GPU 使用率、システム消費電力、充電電力、アダプタ入力、SoC 温度、ファン回転数をまとめて表示。
- CPU、GPU、電力、温度、冷却について、それぞれ直近 60 秒のグラフを表示。
- 各ファンの現在・最低・最高 RPM を確認。ファンレス機種やデータが取得できない状態も明示します。
- ファンレスと検出された Mac ではファン制御を非表示にします。ファンを搭載する旧型 Intel MacBook Air では表示を維持します。
- ファンの目標値を読み取り・検証できる対応機種では、15・30・60 分の「Maximum Cooling（最大冷却）」を macOS 標準の管理者認証で開始できます。
- Maximum Cooling は全ファンをハードウェアが報告する最高回転数まで同時に引き上げます。任意の RPM 指定は行わず、macOS が選んだ回転数を下げません。
- システム電力と充電電力はメニューバーの指標やダッシュボードに追加可能。どちらも初期状態では無効です。

### プロセスの監視と管理

専用テーブルでリソースを消費しているプロセスを確認し、その場で操作できます。

- プロセス名、PID、CPU、メモリ、ディスク I/O、ネットワーク通信量、スレッド数、実行時間を表示。
- 列見出しをクリックして昇順・降順に並べ替え。事前計算した値を使うことで、大量のプロセスでもメモリ順などの並べ替えが応答を妨げません。
- システムソフトウェア・サービス、インストール済みアプリ、プラグイン・ツール、その他を分類し、出所で絞り込み。
- アプリ単位にグループ化し、CPU、メモリ、ディスク、ネットワークの合計を比較。展開した子プロセスも並べ替え可能。
- プロセス名、アプリ名、Bundle ID、PID で検索し、上位 5・10・20・50 件を選択。
- ダブルクリックで直近 1 分間の CPU、メモリ、I/O の詳細を表示。
- 確認後に通常終了または強制終了を実行。

### ハードウェア情報とバッテリー状態

システムレポートの複数階層をたどらずに、ハードウェアと接続情報を確認できます。

- Mac のモデル、チップ、アーキテクチャ、CPU コア数、メモリ、macOS バージョン、稼働時間、熱状態を表示。
- 内蔵・外付けディスプレイ、論理解像度、ピクセル解像度、メインディスプレイの状態を一覧表示。
- USB デバイス、Bluetooth コントローラと接続機器、Wi-Fi インターフェイス、信号強度、速度、チャンネルを確認。
- MacBook では充電残量、最大・設計容量、充放電回数、バッテリー状態、温度、電圧、電流を表示。
- 非対応の項目は取得不可のままとし、推定値で実測値を代用しません。

### ディスプレイ制御

- Hardware グループでディスプレイを選択。現在のモード、モード選択、ハードウェア調整、カラープロファイルをひとつの標準グループ化フォームにまとめます。フィルタは 1 行に並び、モード一覧はページ分けされます。
- 論理解像度、HiDPI、リフレッシュ方式、周波数を組み合わせて絞り込み。各行には解像度、スケーリング、アスペクト比、リフレッシュ情報を表示し、内蔵ノッチ付き画面に合うモードには Notch と表示します。切り替え後は 15 秒以内に確認しなければ自動的に元へ戻ります。
- 公開 API の一覧に出ないネイティブ HiDPI モードも補完し、低解像度で起動した場合でも直接選択可能。切り替え後の実際の出力を検証し、復元に失敗した場合は再試行用に元のモードを保持します。
- システムのモード情報から ProMotion、その他の可変リフレッシュ、固定リフレッシュを区別。固定 120 Hz を ProMotion と表示せず、59.94 Hz などの小数値を保持します。
- 内蔵画面のバックライトと、DDC/CI 対応外付け画面の明るさ・コントラスト・音量を調整。ドラッグすると割合が即時更新され、書き込みはバックグラウンドで集約・検証されます。失敗時は確認済み値に戻り、有効な応答がない項目は操作不可になります。
- インストール済みの RGB ディスプレイ用 ICC プロファイルを切り替えるか、そのディスプレイのシステム標準に戻せます。
- 完全なモード列挙・切り替え、ProMotion 判定、内蔵バックライト、Apple Silicon の DDC は実行時に検出する非公開システム API を利用し、macOS 更新の影響を受ける場合があります。ICC は ColorSync、Intel の DDC は IOKit I2C を使用。DDC の対応状況は画面、ケーブル、アダプタにも依存します。

### ポートとダウンロード

- **ポート使用状況：** TCP・UDP の待ち受けポート、アドレス、PID、プロセス、所有アプリを確認。絞り込み、コピー、ローカルアドレスの表示、プロセス終了に対応。
- **ダウンロード整理：** インストーラ、アーカイブ、重複、不完全なダウンロード、大きいファイル、古いファイルを分類。
- 重複は内容のハッシュで確認し、各グループに最低 1 つを残します。
- Recommended Selection は不完全なダウンロード、古いインストーラやアーカイブ、重複グループの古いコピーだけを選択します。
- ダウンロードは確認後に必ずゴミ箱へ移動し、自動的に完全削除しません。

### スタートアップ項目

ログイン時に開く項目、バックグラウンドタスク、無効になった設定を分けて表示し、実行中かどうかと起動許可を区別します。

- macOS のログイン項目を読み取り、アプリの追加・削除・場所の表示に対応。
- ユーザーとサードパーティの `launchd` タスクを調べ、許可、実行状態、トリガー、所有アプリを表示。
- 対象がない項目、無効な設定、削除済みアプリの残留設定を「Needs Attention」に集め、確認後に無効化・削除。
- システム項目、共有設定、関連が不明確な項目は慎重に扱い、削除対象として初期選択しません。

### 不要ファイルのスキャンと削除

見つかった内容を確認してから、削除する項目を選べます。

- ユーザーキャッシュ、ログ、診断レポート、開発者向けファイルをスキャン。
- 分類別にサイズ、パス、項目を確認し、個別選択。
- 処理中のファイルと全体の進行状況を表示。完了時は要約を表示し、別の結果ウインドウで個別の状態、パス、失敗理由を確認できます。
- キャッシュはゴミ箱へ移動するか完全削除するか選択可能。初期設定はゴミ箱です。
- 失敗理由を保持し、権限の問題を解決した後に再試行できます。

### アプリと関連ファイルの削除

アプリ本体と関連データを同じ確認フローで扱います。

- 標準のアプリフォルダをスキャンし、アプリの状態、場所、サイズを表示。
- Bundle ID、関連データ、システムに登録された別のコピーを識別。
- ログイン項目、Launch Agent、バックグラウンド設定を分析し、確実な関連、可能性のある関連、共有項目を区別。
- 専用画面でアプリ本体、個々の残留ファイル、削除可能な起動設定を確認。
- 削除パスと進行状況を表示し、別の結果ウインドウに成功、失敗理由、権限対応を集約。
- `/Applications` の保護されたアプリは、確認直後に標準の管理者認証を表示します。最初に失敗させて再試行する必要はありません。
- アプリ本体を削除できることを確かめてから関連データを処理し、データだけ消えてアプリが残る状態を避けます。

### ディスクとリソースの管理

容量を消費しているファイルを探せます。

| ツール | 用途 |
| --- | --- |
| **Large Files** | 指定フォルダからしきい値を超えるファイルを見つけ、サイズ順に確認 |
| **Duplicates** | サイズと内容ハッシュで重複を検証し、各グループに最低 1 つを保持 |
| **Quick Memory Release** | 標準の管理者認証を使い、実行中のアプリを閉じずに、対象となる非アクティブなファイルキャッシュの回収を macOS に要求 |

大きいファイルと重複ファイルは、標準でユーザーの `Downloads`、`Desktop`、`Documents`、`Movies` をスキャンします。対象フォルダは設定で追加・削除できます。

## 主な利用例

- **Mac が熱い：** CPU 順に並べ、継続して負荷の高いプロセスと直近 1 分の活動を確認。
- **メモリプレッシャーが高い：** メモリ順で主な使用元を調べ、必要に応じて Quick Memory Release を使用。
- **ディスク容量が少ない：** 不要ファイル、大きいファイル、重複を順に確認。
- **アプリの残留データ：** 関連データや別のコピーも確認してから削除。
- **状態をひと目で確認：** CPU、メモリ、通信速度をメニューバーに表示。
- **ポートが使用中：** ポート番号でアプリを調べ、ローカルアドレスを開くかプロセスを終了。
- **発熱や大きなファン音：** CPU、消費電力、温度、ファンのグラフを比較。
- **古い起動設定：** Needs Attention で対象が消えたログイン項目やバックグラウンド設定を確認。
- **ダウンロードの整理：** インストーラ、アーカイブ、重複、古いファイルを分類して確認。
- **ハードウェアの確認：** チップ、メモリ、ディスプレイ、無線接続、バッテリーをまとめて確認。

## ダウンロードとインストール

1. [GitHub Releases](https://github.com/shenmuoso/mac-scope/releases) から最新の `MacScope-*.dmg` をダウンロードします。
2. DMG を開き、`MacScope.app` を `Applications` フォルダへドラッグします。
3. 「アプリケーション」から MacScope を起動します。

> [!IMPORTANT]
> 現在のリリースは ad-hoc 開発署名を使用し、Apple Developer ID による公証は行っていません。このリポジトリの Releases から取得したパッケージだけを開いてください。MacScope 独自の画面に管理者パスワードを入力させることはありません。

### 初回起動

macOS が開発元を確認できない、または起動をブロックする場合：

1. `MacScope.app` が「アプリケーション」にあることを確認し、一度起動を試します。
2. システムの警告を「完了」で閉じます。
3. Apple メニュー > システム設定 > プライバシーとセキュリティを開きます。
4. セキュリティの項目までスクロールし、MacScope の起動がブロックされた通知を探します。
5. 「このまま開く」をクリックし、Touch ID または管理者パスワードで認証します。
6. 最後の確認画面で「開く」をクリックします。同じビルドでは通常、再確認は不要です。

Finder の「アプリケーション」で `MacScope.app` を右クリックして「開く」を選び、再度確認する方法もあります。別の ad-hoc 署名ビルドに置き換えると、確認が再び必要になることがあります。

## 設定

表示設定は macOS の `UserDefaults` に保存されます。ログイン時の起動とプライバシー権限は macOS が管理します。

| 分類 | 設定項目 |
| --- | --- |
| **監視** | 0.5/1/2/5 秒の更新間隔、上位 5/10/20/50 プロセス、摂氏・華氏 |
| **メニューバー** | 有効・無効、アイコン・コンパクト表示、最大 3 指標、電力、モジュール順、プロセス順と件数、Color Mode |
| **外観** | システム準拠・ライト・ダーク、アクセント色、Glass/Balanced/Frosted、半透明サイドバー、Dock アイコン表示と外観 |
| **クリーンアップ** | キャッシュ処理、事前確認、大きいファイルと重複のしきい値、ダウンロードの経過期間、対象フォルダ |
| **権限** | ログイン時に起動、フルディスクアクセス設定、必要に応じた管理者認証の説明 |
| **アプリの言語** | 英語または簡体字中国語。初期設定は英語 |

設定ファイルの保存先：

```text
~/Library/Preferences/com.shenmuoso.macscope.plist
```

## プライバシー・権限・安全性

- システム指標、プロセス情報、スキャン結果はローカルで処理し、アップロードしません。
- 更新確認は GitHub の最新リリース情報だけを取得し、新版があるとサイドバー下部にダウンロード入口を表示します。
- ファイルは標準でゴミ箱に移動し、ゴミ箱を自動で空にしません。
- アプリ、残留ファイル、大きいファイル、重複ファイルは必ずゴミ箱に移動し、直接完全削除しません。
- ダウンロード整理はユーザーの `Downloads` のみを調べ、処理前に分類、パス、サイズ、更新日時を表示します。
- 設定で許可した場合に限り、再生成可能なキャッシュと開発者向けファイルを完全削除できます。
- 一部の Library フォルダにはフルディスクアクセスが必要です。Settings > Permissions からシステム設定を開けます。
- 保護されたアプリの削除やファイルキャッシュの解放は、実行前に標準の macOS 管理者認証を表示します。
- ファン制御の開始・復元も同じ認証を使用。ハッシュを検証した一時 Helper を `/var/tmp` から実行し、終了後に削除します。常駐 root サービスはインストールしません。
- 管理者パスワードを読み取り、受け取り、保存することはありません。
- シンボリックリンクとアプリバンドル内部をスキップし、選択したフォルダの範囲を越えてスキャンしません。

### フルディスクアクセスを有効にする

1. MacScope の Settings > Permissions > Open Full Disk Access Settings を開きます。
2. システム設定で MacScope のスイッチを有効にします。
3. 有効でもアクセスできない場合は `−` で削除し、`+` から `/Applications/MacScope.app` を再追加します。
4. MacScope を終了し、開き直します。

ad-hoc 署名では、テストビルドの置き換えでアプリの識別情報が変わっても、古い権限項目が残る場合があります。その際は削除して再追加してください。

## 動作要件

- macOS 13 Ventura 以降。
- 現在の GitHub Release DMG は Apple Silicon 向けです。Intel Mac は対応する Swift ツールチェーンでソースからビルドできます。
- ネイティブアプリに Python、Textual、Homebrew、その他のランタイムは不要です。
- 温度は Mac と macOS が公開する IOHID センサーに依存します。温度を取得できなくても、他の監視機能は動作します。

## よくある質問

### 最初の CPU、ディスク、ネットワークの値がゼロなのはなぜですか？

速度は 2 回のシステムカウンタの差から計算します。1 回分の更新間隔が経過すると、現在値が表示されます。

### 一部のファイルにフルディスクアクセスが必要なのはなぜですか？

macOS はユーザーの Library の一部を保護しています。MacScope は保護を回避せず、権限の問題を表示します。許可した後に再スキャンしてください。

スイッチが有効でも制限される場合は、権限項目を削除し、`/Applications/MacScope.app` を再追加してからアプリを再起動します。

### MacScope は管理者パスワードを見られますか？

いいえ。入力ダイアログと認証は macOS が処理し、MacScope は許可されたかどうかだけを受け取ります。

### 温度を取得できないのはなぜですか？

利用できるセンサーはモデルと macOS バージョンにより異なります。CPU、メモリ、ディスク、ネットワーク、プロセス監視には影響しません。

### 電力やファンの値を取得できないのはなぜですか？

MacScope はハードウェアと macOS が実際に提供する値だけを表示します。ファンレス、電源未接続、センサー値がない場合に推定値で補いません。

### Maximum Cooling が使えないのはなぜですか？

ファン数、ハードウェアの最高回転数、目標回転数を読み取れ、認証後に書き込み結果を検証できる場合だけ制御を有効にします。ファンレス Mac では非表示にし、未知の SMC 形式や書き込み拒否時は読み取り専用です。Apple の非公開 SMC API を使う実験的な機能のため、モデルや macOS 更新によって使用できない場合があります。

## ソースからビルド

macOS 13+、Xcode Command Line Tools が必要です。Swift 6 ツールチェーンを推奨します。

```bash
git clone git@github.com:shenmuoso/mac-scope.git
cd mac-scope
native/scripts/run_app.sh debug
```

ネイティブアプリのみをビルド：

```bash
native/scripts/build_app.sh release
```

配布用 DMG をビルド：

```bash
native/scripts/build_dmg.sh release
```

標準の出力先：

```text
native/build/MacScope-0.4.13.dmg
```

以前の Python/Textual ターミナル版は互換性と履歴参照のためリポジトリに残していますが、ネイティブアプリの実行には不要です。
