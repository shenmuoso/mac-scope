> [!TIP]
> **0.4.13: 네이티브 그룹형 화면과 디스플레이 제어.** 시스템 정보, 디스플레이, 배터리, 성능, 메모리 화면에 표준 그룹형 폼을 적용했습니다. 해상도, HiDPI, 재생률을 전환하고, 지원되는 하드웨어의 밝기, 명암, 음량, ICC 프로파일을 조정할 수 있습니다.

MacScope는 Mac의 주요 상태를 깔끔한 네이티브 인터페이스에 모아 보여 줍니다. SwiftUI와 AppKit으로 개발했으며 Electron, 내장 브라우저, 추가 런타임을 포함하지 않습니다. 터미널, Python, Homebrew 없이 설치 후 바로 사용할 수 있습니다.

## MacScope를 선택하는 이유

| | 제공하는 경험 |
| --- | --- |
| **네이티브 인터페이스** | macOS 표준 윈도우, 메뉴, 표, 설정, 인증 대화상자, 라이트·다크 모드 |
| **가벼운 구성** | 작은 앱 크기, 추가 런타임이나 무거운 웹 컨테이너 없이 실행 |
| **통합된 정보** | CPU, 전력, 온도, 팬, 메모리, 디스크, 네트워크, 프로세스, 관리 도구를 한곳에서 확인 |
| **명확한 작업** | 검색 결과, 파일 경로, 진행 상황, 실패 이유를 확인하고 직접 삭제 대상 선택 |
| **로컬 처리** | 모니터링과 파일 분석은 Mac 안에서 수행하며 시스템 정보와 검색 결과를 업로드하지 않음 |

## 주요 기능

### 네이티브 메뉴 막대 모니터링

메인 윈도우를 열어 두지 않아도 Mac의 상태를 확인할 수 있습니다.

- 흑백 아이콘만 표시하거나 최대 3개의 실시간 지표를 간결하게 표시합니다.
- CPU, GPU(Apple Silicon), 메모리, 디스크, 네트워크, 온도, 시스템 소비 전력, 충전 전력을 선택하고 순서를 바꿀 수 있습니다. GPU와 전력 지표는 기본적으로 꺼져 있습니다.
- 업로드·다운로드 속도는 두 줄로 표시합니다. 각 지표의 너비가 고정되어 값이 바뀌어도 다른 메뉴 막대 아이콘이 밀리지 않습니다.
- 아이콘을 클릭하면 대시보드에서 최근 1분간의 활동을 확인할 수 있습니다.
- CPU, 메모리, 디스크, 네트워크 사용량순으로 상위 프로세스를 확인합니다.
- 대시보드 모듈과 프로세스 수를 조정할 수 있으며, 메인 윈도우를 닫아도 모니터링은 계속됩니다.
- 기본은 단색 표시입니다. Color Mode를 켜면 차트와 실시간 상태에만 색상을 적용합니다.
- 포인터가 패널에 들어왔다가 벗어나면 약 0.25초 후 자동으로 닫힙니다. Settings > Menu Bar에서 끌 수 있습니다.
- 메인·설정·도움말 윈도우는 연속된 반투명 사이드바와 단색 본문 배경을 사용합니다. macOS 26+에서는 사이드바, 메뉴 막대 패널, 결과 대화상자에 네이티브 Liquid Glass를 적용하고 외관에 맞춰 배경을 조정합니다. Settings > Appearance > Liquid Glass에서 Glass, Balanced, Frosted를 선택하면 즉시 적용되고 저장됩니다.
- 표준 제목 막대와 회색 그룹 영역으로 상세 화면을 구분합니다. 정보 화면은 SwiftUI 그룹형 폼을 사용하고, 표 화면은 여백과 상태 막대를 통일해 구분선과 테두리를 줄였습니다.
- 이전 macOS에서는 네이티브 흐림 효과를 사용합니다. 모든 소재는 투명도 줄이기와 대비 증가 설정을 따릅니다.
- Settings > Appearance에서 Dock 아이콘을 숨길 수 있습니다. 메뉴 막대에서 윈도우와 설정을 열 수 있지만 앱 전환기에는 표시되지 않습니다. Dock과 메뉴 막대 중 하나는 활성화해야 합니다.
- Dock 아이콘은 기본적으로 앱 외관을 따르며, Follow System에서는 시스템의 라이트·다크 전환도 따릅니다. Settings > Appearance > Dock Icon에서 Light 또는 Dark를 별도로 선택할 수 있습니다. Finder 아이콘 외관은 macOS 아이콘 스타일 설정을 따릅니다.

### 실시간 리소스 모니터링

Mac이 뜨거워지거나 팬이 빨라지거나 네트워크가 느려질 때 실제 상태를 확인하세요.

- **CPU:** 전체·사용자·시스템 사용률과 SoC 온도.
- **GPU(Apple Silicon 전용):** 전체 사용률과 최근 60초 기록. 시스템이 제공하면 렌더러와 타일러 사용률도 표시하며 관리자 권한은 필요하지 않습니다.
- **메모리:** 사용량, 전체 용량, 사용 가능 용량, 실시간 사용률.
- **디스크:** 데이터 볼륨 용량, 읽기·쓰기 속도.
- **네트워크:** 실시간 다운로드·업로드 속도.
- **개요:** 왼쪽 원형 지표에 현재 값을 표시하고, 오른쪽 통합 차트에서 최근 60초의 시스템 부하와 디스크·네트워크 활동을 비교합니다.
- **상태 색상:** 사용률, 네트워크 속도, 온도 구간을 색상으로 구분합니다.
- **새로 고침:** 일시 정지, 즉시 갱신, `0.5`, `1`, `2`, `5`초 간격을 지원합니다.

### 성능, 전력, 냉각

높은 부하, 온도 변화, 팬 동작을 같은 화면에서 비교할 수 있습니다.

- CPU·GPU 사용률, 시스템 소비 전력, 충전 전력, 어댑터 입력, SoC 온도, 팬 회전수를 함께 표시합니다.
- CPU, GPU, 전력, 온도, 냉각에 대한 개별 60초 추세 차트를 제공합니다.
- 각 팬의 현재·최저·최고 RPM을 표시하며, 팬이 없는 모델과 센서 데이터를 읽을 수 없는 상태를 명확히 구분합니다.
- 팬이 없는 것으로 감지된 Mac에서는 팬 제어 영역을 숨깁니다. 팬이 장착된 구형 Intel MacBook Air에서는 유지합니다.
- 팬 목표값을 읽고 검증할 수 있는 지원 모델에서 15·30·60분 동안 Maximum Cooling을 실행할 수 있으며, macOS 표준 관리자 인증을 거칩니다.
- Maximum Cooling은 모든 팬을 하드웨어가 보고한 최고 회전수로 함께 올립니다. 임의의 RPM 설정은 지원하지 않으며 macOS가 선택한 속도를 낮추지 않습니다.
- 시스템 전력과 충전 전력을 메뉴 막대 지표나 대시보드에 추가할 수 있습니다. 둘 다 기본적으로 꺼져 있습니다.

### 프로세스 모니터링 및 관리

전용 표에서 리소스를 소비하는 프로세스를 확인하고 바로 조치할 수 있습니다.

- 이름, PID, CPU, 메모리, 디스크 I/O, 네트워크 트래픽, 스레드 수, 실행 시간을 표시합니다.
- 열 제목을 클릭해 오름차순·내림차순으로 정렬합니다. 미리 계산한 정렬 값을 사용해 프로세스가 많아도 메모리 정렬 등으로 화면이 멈추지 않도록 합니다.
- 시스템 소프트웨어·서비스, 설치된 앱, 플러그인·도구, 기타 출처를 구분하고 출처별로 필터링합니다.
- 앱별로 프로세스를 묶어 CPU, 메모리, 디스크, 네트워크 사용량을 합산하며, 펼친 하위 프로세스도 정렬할 수 있습니다.
- 프로세스명, 앱 이름, Bundle ID, PID로 검색하고 상위 5·10·20·50개를 표시합니다.
- 두 번 클릭하면 최근 1분의 CPU, 메모리, I/O 상세 기록을 확인할 수 있습니다.
- 확인 후 정상 종료 또는 강제 종료할 수 있습니다.

### 하드웨어 정보 및 배터리 성능 상태

시스템 리포트의 여러 단계를 탐색하지 않고 하드웨어와 연결 상태를 확인할 수 있습니다.

- Mac 모델, 칩, 아키텍처, CPU 코어, 메모리, macOS 버전, 가동 시간, 열 상태를 표시합니다.
- 내장·외장 디스플레이, 논리·픽셀 해상도, 메인 디스플레이 상태를 표시합니다.
- USB 기기, Bluetooth 컨트롤러와 연결 기기, Wi-Fi 인터페이스·신호·속도·채널을 확인합니다.
- MacBook에서는 충전량, 최대·설계 용량, 사이클 수, 배터리 상태, 온도, 전압, 전류를 표시합니다.
- 지원하지 않는 항목은 사용 불가로 유지하며 추정값을 실제 측정값처럼 표시하지 않습니다.

### 디스플레이 제어

- Hardware 그룹에서 디스플레이를 선택합니다. 하나의 네이티브 그룹형 폼에 현재 모드, 모드 선택, 하드웨어 조정, 색상 프로파일을 정리했습니다. 필터는 한 줄에 배치하고 모드 목록은 페이지로 나눕니다.
- 논리 해상도, HiDPI, 재생 유형, 재생률을 조합해 필터링합니다. 각 행에 해상도, 배율, 화면 비율, 재생 정보가 표시되며 내장 노치 화면에 맞는 모드는 Notch로 표시합니다. 변경 후 15초 안에 확인하지 않으면 이전 모드로 자동 복원합니다.
- 공개 모드 목록에서 누락된 네이티브 HiDPI 모드도 포함해 낮은 해상도로 시작해도 직접 선택할 수 있습니다. 변경 후 실제 출력을 검증하며, 복원이 실패하면 재시도를 위해 원래 모드를 보관합니다.
- 시스템 정보로 ProMotion, 기타 가변 재생률, 고정 재생률을 구분합니다. 고정 120 Hz를 ProMotion으로 표시하지 않으며 59.94 Hz 같은 소수점 값도 유지합니다.
- 내장 화면의 백라이트와 DDC/CI를 지원하는 외장 화면의 밝기·명암·음량을 조절합니다. 드래그 시 백분율이 즉시 바뀌고 백그라운드 쓰기는 병합 후 검증합니다. 실패하면 확인된 값으로 돌아가며 유효한 응답이 없는 항목은 사용할 수 없습니다.
- 설치된 RGB 디스플레이 ICC 프로파일을 전환하거나 디스플레이의 시스템 기본 프로파일로 복원합니다.
- 전체 모드 열거·전환, ProMotion 감지, 내장 백라이트, Apple Silicon DDC는 실행 시 감지하는 비공개 시스템 인터페이스를 사용하므로 macOS 업데이트의 영향을 받을 수 있습니다. ICC는 ColorSync, Intel DDC는 IOKit I2C를 사용합니다. 디스플레이, 케이블, 어댑터에 따라서도 DDC 지원 여부가 달라집니다.

### 포트 및 다운로드

- **포트 사용 현황:** TCP·UDP 수신 대기 포트, 주소, PID, 프로세스, 소유 앱을 확인합니다. 필터링, 복사, 로컬 주소 열기, 프로세스 종료를 지원합니다.
- **다운로드 정리:** 설치 파일, 압축 파일, 중복 다운로드, 미완료 다운로드, 대용량 파일, 오래된 파일을 분류합니다.
- 콘텐츠 해시로 중복을 검증하고 그룹마다 최소 한 개의 사본을 유지합니다.
- Recommended Selection은 미완료 다운로드, 오래된 설치·압축 파일, 중복 그룹의 오래된 사본만 선택합니다.
- 다운로드 파일은 확인 후 항상 휴지통으로 이동하며 자동으로 영구 삭제하지 않습니다.

### 시작 항목 관리

로그인 시 열기, 백그라운드 작업, 오래된 시작 설정을 분리해 실행 중인 상태와 시작 권한을 구분합니다.

- macOS 로그인 항목을 읽고 앱 추가·제거·위치 확인을 지원합니다.
- 사용자 및 타사 `launchd` 작업을 검색해 권한, 실행 상태, 트리거, 소유 앱을 표시합니다.
- 대상이 없거나 구성이 잘못됐거나 삭제된 앱이 남긴 항목을 Needs Attention에 모아 확인 후 비활성화하거나 제거합니다.
- 시스템 항목, 공유 설정, 연관성이 불명확한 항목은 보수적으로 처리하며 기본 삭제 대상으로 선택하지 않습니다.

### 불필요한 파일 검색 및 정리

검색된 내용을 먼저 확인한 뒤 무엇을 제거할지 결정할 수 있습니다.

- 사용자 캐시, 로그, 진단 보고서, 개발자 파일을 검색합니다.
- 분류별 크기, 경로, 개별 항목을 확인하고 따로 선택할 수 있습니다.
- 정리 중인 파일과 전체 진행 상황을 표시합니다. 완료 후 요약을 제공하며 별도의 결과 윈도우에서 항목별 상태, 경로, 실패 이유를 확인할 수 있습니다.
- 캐시는 휴지통으로 이동하거나 영구 삭제하도록 설정할 수 있습니다. 기본값은 휴지통입니다.
- 실패한 항목의 이유를 유지하므로 권한 문제를 해결한 뒤 다시 시도할 수 있습니다.

### 앱 제거 및 관련 파일 정리

앱 본체와 관련 데이터를 하나의 확인 과정에서 검토합니다.

- 표준 앱 폴더를 검색해 상태, 위치, 크기를 표시합니다.
- Bundle ID, 관련 데이터, 시스템에 등록된 다른 사본을 식별합니다.
- 연결된 로그인 항목, Launch Agent, 백그라운드 설정을 분석하고 확실한 연관, 가능한 연관, 공유 항목을 구분합니다.
- 전용 확인 화면에서 앱, 개별 잔여 파일, 제거 가능한 시작 설정을 검토합니다.
- 제거 경로와 실시간 진행 상황을 표시하고 별도 결과 윈도우에 성공, 실패 이유, 권한 조치를 모아 보여 줍니다.
- `/Applications`의 보호된 앱은 확인 직후 macOS 표준 관리자 인증을 표시합니다. 먼저 실패한 뒤 재시도할 필요가 없습니다.
- 앱 자체를 제거할 수 있는지 확인한 뒤 관련 데이터를 처리해 데이터만 지워지고 앱은 남는 상황을 방지합니다.

### 디스크 및 리소스 도구

어떤 파일이 공간을 차지하는지 확인할 수 있습니다.

| 도구 | 용도 |
| --- | --- |
| **Large Files** | 선택한 폴더에서 기준 크기를 넘는 파일을 찾고 크기순으로 확인 |
| **Duplicates** | 크기와 콘텐츠 해시로 중복을 검증하고 그룹마다 최소 한 개의 사본 유지 |
| **Quick Memory Release** | 실행 중인 앱을 닫지 않고 표준 관리자 인증을 통해 회수 가능한 비활성 파일 캐시 반환을 macOS에 요청 |

대용량 파일과 중복 파일은 기본적으로 사용자의 `Downloads`, `Desktop`, `Documents`, `Movies`를 검색합니다. 설정에서 검색 폴더를 추가하거나 제거할 수 있습니다.

## 활용 예시

- **Mac이 뜨거워질 때:** CPU순으로 정렬해 지속적으로 사용량이 높은 프로세스와 최근 1분 활동을 확인합니다.
- **메모리 압력이 높을 때:** 메모리순으로 주요 사용자를 확인하고 필요하면 Quick Memory Release를 사용합니다.
- **디스크가 부족할 때:** 불필요한 파일, 대용량 파일, 중복 파일을 검토합니다.
- **앱의 잔여 데이터:** 관련 데이터와 다른 사본을 확인한 뒤 함께 제거합니다.
- **간단한 상태 확인:** CPU, 메모리, 네트워크 속도를 메뉴 막대에 표시합니다.
- **포트가 사용 중일 때:** 포트 번호로 앱을 찾아 로컬 주소를 열거나 프로세스를 종료합니다.
- **발열이나 팬 소음:** CPU, 전력, 온도, 팬 차트를 비교해 부하와 냉각의 관계를 확인합니다.
- **오래된 시작 설정:** Needs Attention에서 대상이 사라진 로그인 항목과 백그라운드 설정을 확인합니다.
- **복잡한 다운로드 폴더:** 설치 파일, 압축 파일, 중복 다운로드, 오래된 파일을 분류해 검토합니다.
- **하드웨어 점검:** 칩, 메모리, 디스플레이, 무선 연결, 배터리 상태를 한곳에서 확인합니다.

## 다운로드 및 설치

1. [GitHub Releases](https://github.com/shenmuoso/mac-scope/releases)에서 최신 `MacScope-*.dmg`를 다운로드합니다.
2. DMG를 열고 `MacScope.app`을 `Applications` 폴더로 드래그합니다.
3. 응용 프로그램 폴더에서 MacScope를 실행합니다.

> [!IMPORTANT]
> 현재 릴리스는 ad-hoc 개발 서명을 사용하며 Apple Developer ID 공증을 받지 않았습니다. 이 저장소의 Releases에서 다운로드한 패키지만 여세요. MacScope는 자체 화면에 관리자 암호를 입력하도록 요구하지 않습니다.

### 처음 실행하기

macOS가 개발자를 확인할 수 없거나 실행을 차단하는 경우:

1. `MacScope.app`이 응용 프로그램 폴더에 있는지 확인하고 한 번 실행을 시도합니다.
2. 완료를 누르거나 시스템 알림을 닫습니다.
3. Apple 메뉴 > 시스템 설정 > 개인정보 보호 및 보안을 엽니다.
4. 보안 영역까지 스크롤해 MacScope 실행이 차단되었다는 알림을 찾습니다.
5. 확인 없이 열기를 클릭하고 Touch ID 또는 관리자 암호로 승인합니다.
6. 마지막 대화상자에서 열기를 클릭합니다. 같은 빌드는 보통 다시 승인할 필요가 없습니다.

Finder의 응용 프로그램 폴더에서 `MacScope.app`을 오른쪽 클릭해 열기를 선택하고 다시 확인할 수도 있습니다. 다른 ad-hoc 서명 빌드로 교체하면 재확인이 필요할 수 있습니다.

## 설정

인터페이스 설정은 macOS `UserDefaults`에 저장됩니다. 로그인 시 실행과 개인정보 권한은 macOS가 관리합니다.

| 분류 | 설정 항목 |
| --- | --- |
| **모니터링** | 0.5/1/2/5초 갱신 간격, 상위 5/10/20/50개 프로세스, 섭씨·화씨 |
| **메뉴 막대** | 켜기·끄기, 아이콘·간결한 지표, 최대 3개 지표, 전력, 모듈 순서, 프로세스 정렬·개수, Color Mode |
| **외관** | 시스템·라이트·다크, 강조 색상, Glass/Balanced/Frosted, 반투명 사이드바, Dock 아이콘 표시·외관 |
| **정리** | 캐시 처리 방식, 실행 전 확인, 대용량·중복 파일 기준, 다운로드 경과 기간, 검색 폴더 |
| **권한** | 로그인 시 실행, 전체 디스크 접근 권한 설정, 필요할 때의 관리자 인증 안내 |
| **앱 언어** | 영어 또는 중국어 간체, 기본값은 영어 |

설정 파일 위치:

```text
~/Library/Preferences/com.shenmuoso.macscope.plist
```

## 개인정보, 권한, 안전

- 시스템 지표, 프로세스 정보, 검색 결과는 로컬에서 처리하며 업로드하지 않습니다.
- 업데이트 확인은 GitHub 최신 릴리스 정보만 요청합니다. 새 버전이 있으면 사이드바 하단에 다운로드 항목이 표시됩니다.
- 파일은 기본적으로 휴지통으로 이동하며 휴지통을 자동으로 비우지 않습니다.
- 앱, 잔여 파일, 대용량 파일, 중복 파일은 항상 휴지통으로 이동하고 바로 영구 삭제하지 않습니다.
- 다운로드 정리는 사용자의 `Downloads`만 검색하며 정리 전에 분류, 경로, 크기, 수정 날짜를 표시합니다.
- 설정에서 허용한 경우에만 재생성 가능한 캐시와 개발자 파일을 영구 삭제할 수 있습니다.
- 일부 Library 폴더에는 전체 디스크 접근 권한이 필요합니다. Settings > Permissions에서 시스템 설정을 열 수 있습니다.
- 보호된 앱 제거나 파일 캐시 반환은 실행 전에 macOS 표준 관리자 인증을 표시합니다.
- 팬 제어 시작·복원에도 같은 인증을 사용합니다. 해시를 검증한 임시 Helper가 `/var/tmp`에서 실행되고 종료 후 삭제되며 상주 root 서비스를 설치하지 않습니다.
- 관리자 암호를 읽거나 받거나 저장하지 않습니다.
- 심볼릭 링크와 앱 번들 내부는 건너뛰어 선택한 폴더의 경계를 벗어나 검색하지 않습니다.

### 전체 디스크 접근 권한 활성화

1. MacScope에서 Settings > Permissions > Open Full Disk Access Settings를 엽니다.
2. 시스템 설정에서 MacScope 옆의 스위치를 켭니다.
3. 이미 켜져 있는데 접근할 수 없다면 `−`로 제거한 뒤 `+`로 `/Applications/MacScope.app`을 다시 추가합니다.
4. MacScope를 종료하고 다시 실행합니다.

ad-hoc 서명에서는 테스트 빌드를 교체하면 앱 식별 정보가 바뀌어도 이전 권한 항목이 남을 수 있습니다. 이 경우 제거 후 다시 추가해야 할 수 있습니다.

## 시스템 요구 사항

- macOS 13 Ventura 이상.
- 현재 GitHub Release DMG는 Apple Silicon용입니다. Intel Mac은 호환되는 Swift 도구 체인으로 소스에서 빌드할 수 있습니다.
- 네이티브 앱에는 Python, Textual, Homebrew 또는 다른 런타임이 필요하지 않습니다.
- 온도는 Mac과 macOS가 제공하는 IOHID 센서에 따라 달라집니다. 온도를 읽을 수 없어도 다른 모니터링 기능은 계속 작동합니다.

## 자주 묻는 질문

### 처음 CPU, 디스크, 네트워크 값이 0인 이유는 무엇인가요?

속도는 두 번의 시스템 카운터 차이로 계산합니다. 한 번의 갱신 주기가 지나면 실시간 값이 표시됩니다.

### 일부 파일에 전체 디스크 접근 권한이 필요한 이유는 무엇인가요?

macOS는 사용자 Library의 일부 폴더를 보호합니다. MacScope는 보호를 우회하지 않고 권한 문제를 알립니다. 권한을 부여한 후 다시 검색하세요.

스위치가 켜져 있어도 제한된다면 권한 항목을 제거하고 `/Applications/MacScope.app`을 다시 추가한 다음 앱을 재시작하세요.

### MacScope가 관리자 암호를 볼 수 있나요?

아니요. 암호 입력과 인증은 macOS가 처리하며 MacScope는 승인 결과만 받습니다.

### 온도를 읽을 수 없는 이유는 무엇인가요?

사용 가능한 센서는 Mac 모델과 macOS 버전에 따라 다릅니다. CPU, 메모리, 디스크, 네트워크, 프로세스 모니터링에는 영향을 주지 않습니다.

### 전력이나 팬 값을 읽을 수 없는 이유는 무엇인가요?

MacScope는 하드웨어와 macOS가 실제로 제공하는 값만 표시합니다. 팬이 없거나 전원이 연결되지 않았거나 센서 값이 없을 때 추정값으로 채우지 않습니다.

### Maximum Cooling을 사용할 수 없는 이유는 무엇인가요?

팬 수, 하드웨어 최고 RPM, 목표 RPM을 읽고 인증 후 쓰기 결과를 검증할 수 있을 때만 제어를 활성화합니다. 팬이 없는 Mac은 제어 영역을 숨기며 알 수 없는 SMC 형식이나 쓰기 거부 시 읽기 전용으로 유지합니다. Apple 비공개 SMC 인터페이스를 사용하는 실험적 기능이므로 모델이나 macOS 업데이트에 따라 사용할 수 없을 수 있습니다.

## 소스에서 빌드

macOS 13+, Xcode Command Line Tools가 필요하며 Swift 6 도구 체인을 권장합니다.

```bash
git clone git@github.com:shenmuoso/mac-scope.git
cd mac-scope
native/scripts/run_app.sh debug
```

네이티브 앱만 빌드:

```bash
native/scripts/build_app.sh release
```

배포용 DMG 빌드:

```bash
native/scripts/build_dmg.sh release
```

기본 출력:

```text
native/build/MacScope-0.4.13.dmg
```

이전 Python/Textual 터미널 버전은 호환성과 기록 보존을 위해 저장소에 남아 있지만 네이티브 앱의 실행 의존성은 아닙니다.
